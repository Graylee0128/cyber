網路位置
中控住哪、碰得到誰。Z-EDGE 是一個區（VLAN 50），不是防火牆前的一台機器（spec §5.1）。
EDGE → APP :443 ✓ auth_request EDGE → RED :7681 ✓ ttyd EDGE → BLUE :7681 ✓ ttyd EDGE → MGMT ✗ 契約 5 EDGE → TARGET ✗
Z-EDGE 零持久化：只有 TLS 憑證與反代設定，沒有資料庫連線、沒有座位表、沒有 HMAC secret（spec §5.3）。 它是唯一「未通過任何驗證的流量碰得到」的區——Z-RED 裡至少是已入場的人， 把 Z-EDGE 放得比 Z-RED 寬鬆是反的。
ttyd 因此只能跑在各 seat 自己的容器內：跑在 host 上就是 EDGE → MGMT，直接撞契約 5（spec §5.4）。
